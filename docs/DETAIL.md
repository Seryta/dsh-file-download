# 文件下载

在右侧预览标题栏保存当前文件，无法预览的二进制文件还会在空状态里提供「下载文件」按钮。支持文本、图片、PDF、APK、ZIP 等宿主文件。

## 保存方式

点击时同步把下载地址交给浏览器或系统下载管理器，页面不缓冲完整文件。宿主按 4 MiB 窗口输出，不受官方 `/api/file` 默认 50 MiB 图片上限约束。

- attachment 响应带文件名、媒体类型，中文及撇号、括号等特殊字符使用 RFC 5987 编码。
- 已知大小的文件支持单段和后缀 Range，以及 ETag/If-Range 续传；文件变化后陈旧校验器退回完整响应。
- 本地文件每请求固定一个读取句柄，大小与校验器属于实际打开的对象。每窗保留后端读取权限检查，并与固定句柄的字节对照，避免路径被临时切换后又恢复而混入另一文件。
- 首窗的读取和版本检查在成功响应之前完成；后续窗口、空窗口和 EOF 都检查。已知长度提前 EOF、读盘失败或观察到版本变化会中止下载；首窗变化返回 409，权限和不存在分别返回 403、404。
- 完成、取消、断开及异常都会释放该请求的句柄。字节对照会增加一次窗口读取和元数据检查，内存仍有窗口上限，吞吐量需在实际环境重新测量。

## 探测与恢复

页面后台通过带能力标记的 HEAD 响应确认流式路由。网络错误、401/403 和 5xx 进入有限重试：初次请求后最多再试 3 次，间隔 1/3/10 秒，每次超时 5 秒，网络恢复事件可重新探测。未确认时仍优先流式路由，只有确认 404 缺失才退回官方路由；回退仍受官方大小上限约束，超限会得到 413。点击始终同步，不等待探测。

## 支持范围与边界

- 要求 DSH **0.2.2-rc.3 或更新的 0.2.x**。
- 只在 Web 注册入口；检测到 Desktop 环境时跳过本插件的客户端，原生保存继续由官方文件动作处理。
- 文件名取路径最后一段；同名文件由浏览器自行处理。
- 不报告大小的后端不声明 Content-Length，不提供 Range 和续传，但保留窗口读取及 EOF 版本检查。
- 无宿主路径映射的自定义后端继续通过 DSH 文件系统读取，不在本机猜测远端路径。当前抽象接口没有原子版本读取或不可变快照能力，因而无法对任意后端承诺绝对单版本；普通版本复核不能代替这一上游能力。
- 固定句柄可避免路径换绑，元数据检查可以检测观察到的写入；它们不等于所有文件系统上的不可变快照。
- 更新仓库不等于运行服务已加载修复；启用宿主 HMR 时，可通过 profile 重组或 Plugin Manager 应用变化的宿主模块，无需重启。以操作结果及实际下载请求确认生效；客户端必要时刷新页面。
- 浏览器下载管理器的暂停/恢复、移动端及不同系统仍需相应端到端验收。

## 反向代理

路由带 `X-Accel-Buffering: no`，nginx 通常据此关闭响应缓冲。也可配置较长超时：

```nginx
proxy_buffering off;
proxy_max_temp_file_size 0;
proxy_read_timeout 3600s;
proxy_send_timeout 3600s;
```

代理必须在上游正文异常结束时关闭下游连接，否则中途失败会表现为挂起。历史部署曾验证 Go 门房 v0.5.2 的传播语义；更换或升级代理后需要重新验证。
